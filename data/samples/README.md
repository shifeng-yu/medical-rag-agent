# Knowledge Base Samples

Sample corpora generated by the project's **synthetic data-generation pipeline**
(`scripts/generate_samples.py` / `scripts/generate_local_kb.py`, template-based
realistic simulation) to demonstrate knowledge base structure and run
end-to-end verification. **No real hospital, patient, or consultation data is
included.**

## PubMed Literature (`pubmed/`)

9 medical specialties x 200 articles each = 1,800 abstracts.
Structure mimics PubMed entries (**fictional PMIDs**) for demo purposes; these
are generated samples, not real literature — do not cite them as actual
publications.

## Local Medical KB (`local_kb/`)

4 clinical departments x 200 Q&A pairs each = 800 records.
Template-synthesized QA under the 4 department directions
(心内科 / 内分泌科 / 消化科 / 呼吸科), generated by `scripts/generate_local_kb.py`.

## Keywords (`../common_diseases_drugs.txt`)

83 disease names + 52 drug names for L1 keyword classification.

---

**Compliance Note:** All sample data is synthetically generated for technical
verification only; it contains no real hospital data and no patient-identifiable
information. Medical references inside answers are illustrative and do not
constitute diagnosis or treatment advice.
